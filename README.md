Prop Firm ROI Tracker
Personal dashboard untuk memantau performa finansial trading di berbagai prop firm. Dibangun dengan fokus pada kecepatan input, persistensi data lokal, dan visualisasi ROI yang presisi.

Fitur Utama
Tracking Terpusat: Catat semua spending (eval/activation fee) dan payout dari berbagai prop firm (Apex, Topstep, OFP, dll) dalam satu aplikasi.

Dashboard ROI: Kalkulasi otomatis ROI, Net P&L, Total Spending, dan Total Payout.

Breakdown Per Firm: Tabel perbandingan performa antar prop firm untuk melihat mana yang paling menguntungkan.
Persistence: Data tersimpan permanen di browser (localStorage), tidak perlu database cloud yang ribet.

Data Security: Fitur Export & Import Backup (CSV) untuk keamanan data manual.

Clean UI: Dark mode, layout responsif, dan font monospace untuk presisi finansial.
